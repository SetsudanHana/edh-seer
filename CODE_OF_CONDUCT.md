# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. The short form:

- Be respectful. Disagree with the claim, not the person. A wrong synergy edge is a bug with two
  card names on it, and so is a wrong review comment.
- No harassment, no personal attacks, no publishing of anyone's private information.
- Keep it on topic. Issues and pull requests are about the engine, the site and the cards.

## Enforcement

Report unacceptable behaviour privately through
[GitHub's report form](https://github.com/SetsudanHana/edh-seer/security/advisories/new), which opens
a draft only the maintainer can see. Reports are acknowledged within a week. The maintainer may
edit, remove or reject contributions that break this code, and may block repeat offenders.

This applies in every space the project runs: issues, pull requests, reviews and the live site's
feedback channels.
